Kebijakan Privasi - DriveRouter Google1

Terakhir diperbarui: 31 Oktober 2026.

Data yang diakses

Aplikasi ini mengakses file Google Drive di akun Google Drive milik pemiliknya sendiri, melalui Google Drive API, hanya untuk keperluan sinkronisasi dan penyalinan file dengan rclone.

Data yang dikumpulkan

Aplikasi ini sendiri tidak mengumpulkan, menyimpan, atau membagikan data pribadi ke pihak ketiga. Tidak ada analitik, tidak ada iklan, dan tidak ada pelacakan.

Tempat data disimpan

File tetap berada di akun Google Drive milik pemiliknya. Token akses OAuth disimpan secara lokal di konfigurasi rclone pada perangkat milik pemiliknya, bukan di situs web ini.

Pencabutan akses

Pemiliknya dapat mencabut akses kapan saja melalui Akun Google, Keamanan, Akses pihak ketiga, dan dengan menghapus token dari konfigurasi rclone.

Perubahan

Kebijakan ini dapat diperbarui sewaktu-waktu, dan tanggal di atas akan diubah sesuai pembaruan.
