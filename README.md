# OAuth Branding Pages

Halaman beranda dan kebijakan privasi sederhana untuk dua aplikasi OAuth pemakaian pribadi:

- `drive-router/` — DriveRouter Google1, untuk menghubungkan rclone ke Google Drive milik pemiliknya sendiri.
- `bardi-cctv/` — Bardi CCTV, untuk mengunggah segmen CCTV yang terdeteksi ada gerakan ke Google Drive milik pemiliknya sendiri.

Kedua aplikasi ini bukan layanan publik. Halaman-halaman ini ada semata-mata sebagai tautan beranda dan kebijakan privasi yang diminta halaman Branding Google Cloud saat aplikasi dipublish ke Production.
